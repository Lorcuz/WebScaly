# Security policy

## Supported version

Security fixes target the latest WebScaly release, currently 0.4.0. Update before reporting a problem where possible.

## Report privately

Email **notlorcuz@gmail.com** with the subject `WebScaly security report`. Describe the affected version, a minimal reproduction, impact and any suggested fix. Do not open a public issue with exploit details or include credentials, private video content or browser profiles.

The maintainer will investigate and coordinate disclosure when practical. No guaranteed response time or bounty program is offered. Ordinary playback and interface bugs can be reported through GitHub Issues.
