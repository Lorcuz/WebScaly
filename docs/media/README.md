# WebScaly demonstrations

[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/webscaly/hdcnniaagmhkocoeahemlpgjecgpchfa) · [Project README](../../README.md) · [Source credits and capture details](ATTRIBUTIONS.md)

These examples use **WebScaly 0.3.1**, **Anime4K CNN → Quality**, **2× output scale** and a **1080p output-height limit**. OFF shows the decoded source; ON shows the actual extension output. Presentation crops and resizing apply equally to both sides. Results depend on the source and device.
