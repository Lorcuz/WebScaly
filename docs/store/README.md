# Store artwork

WebScaly is available on the [Chrome Web Store](https://chromewebstore.google.com/detail/webscaly/hdcnniaagmhkocoeahemlpgjecgpchfa). Use [CHROMEWEBSTORE.md](../../CHROMEWEBSTORE.md) as the single source of truth for listing fields, privacy disclosures, permission explanations and future-update steps. The Description text is in [description.txt](description.txt).

The asset directory contains a 128×128 icon, six 1280×800 RGB images, a 440×280 small promo tile and a 1400×560 marquee. For the store's five screenshot slots, use **01-player, 06-hero-detail, 03-popup, 02-settings, 04-site-profiles**, in that order. The About image remains an optional alternative. Image 01 shows enlarged matching detail from the original illustration prepared as a 360p video; image 06 shows matching detail from the 540p Hero film still. Both use actual Anime4K Quality output, with source resolution and visible credits. Other screenshots show the installed extension on an isolated local demonstration website. The popup overview includes an unchanged actual UI capture. `popup-ui.png` is supporting artwork, not a store-sized screenshot.

The [demonstration gallery](../media/README.md) contains a 58-second showcase and full-frame/detail comparisons at 1920×1080, 1280×800 and 1000×1340. Keep the [media credits](../media/ATTRIBUTIONS.md) with shared artwork. The video is also published on YouTube as Unlisted: **https://youtu.be/Oy77dm2rm-s**. Use that URL in the store's Global promo video field. Its [1280×720 thumbnail](../media/WebScaly-youtube-thumbnail-1280x720.png) matches the original 540p source in the video.

Uploading these files to the live listing is a separate action from committing them to GitHub. The new screenshots and promo-video URL are ready for the next listing update.

For future store updates, upload only the generated extension ZIP. Keep artwork and listing text outside it. Preserve compliance/source and notices inside it. The [GitHub repository](https://github.com/Lorcuz/WebScaly), privacy policy and support pages are public; keep those links current. See [repository maintenance](../publishing/GITHUB.md).
