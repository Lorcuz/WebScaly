# Store artwork

WebScaly is available on the [Chrome Web Store](https://chromewebstore.google.com/detail/webscaly/hdcnniaagmhkocoeahemlpgjecgpchfa). Use [CHROMEWEBSTORE.md](../../CHROMEWEBSTORE.md) as the single source of truth for listing fields, privacy disclosures, permission explanations and future-update steps. The Description text is in [description.txt](description.txt).

The asset directory contains a 128×128 icon, five 1280×800 RGB images, a 440×280 small promo tile and a 1400×560 marquee. Image 01 compares matching original and Anime4K Quality frames from *Hero*, with visible CC BY 4.0 attribution. Other screenshots show the installed extension on an isolated local demonstration website. The popup overview includes an unchanged actual UI capture. `popup-ui.png` is supporting artwork, not a store-sized screenshot.

The [demonstration gallery](../media/README.md) contains a 58-second showcase video and additional full-frame/detail comparisons at 1920×1080 and 1280×800. Keep the [media credits](../media/ATTRIBUTIONS.md) with shared artwork. The MP4 is published on GitHub; the store's promotional-video field requires a YouTube URL.

For future store updates, upload only the generated extension ZIP. Keep artwork and listing text outside it. Preserve compliance/source and notices inside it. The [GitHub repository](https://github.com/Lorcuz/WebScaly), privacy policy and support pages are public; keep those links current. See [repository maintenance](../publishing/GITHUB.md).
