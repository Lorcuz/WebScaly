# Store artwork

Use CHROMEWEBSTORE.md as the single source of truth for listing fields, privacy disclosures, permission explanations and submission steps. Paste docs/store/description.txt into the Description field.

The asset directory contains a 128×128 icon, five 1280×800 RGB screenshots, a 440×280 small promo tile and a 1400×560 marquee. Screenshots show the installed extension with test-only loopback permission and original generated video. The popup overview includes an unchanged actual UI capture. popup-ui.png is supporting artwork; do not upload it as a store screenshot.

Upload only the generated extension ZIP. Keep artwork and listing text outside it. Preserve compliance/source and notices inside it. Publish the GitHub repository first so the linked privacy and support pages are live. See docs/publishing/GITHUB.md.
