# Privacy policy

The authoritative public policy is [PRIVACY.md](../../PRIVACY.md) at the repository root, publicly available at https://github.com/Lorcuz/WebScaly/blob/main/PRIVACY.md. Keep this URL in the Chrome Web Store privacy-policy field and review the policy whenever extension behavior changes.

Website addresses, approved origins, preferences, video frames and diagnostics are handled locally for enhancement and access control. There are no automatic uploads, analytics or developer-side browsing/video collection. The policy covers storage/retention, user exports, optional local tab sharing and voluntary support/donation services. Store disclosures must describe local handling too; see CHROMEWEBSTORE.md.
