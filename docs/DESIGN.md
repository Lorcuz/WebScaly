# Design

WebScaly retains dark `#111820`, surface `#18232d`, mint `#79dfbd` and locally bundled Inter. Its new original identity uses three ascending curved scale plates, selected from generated scale concepts for its silhouette at small sizes. Master and actual 16/32/48/128 PNGs are included without source-generation metadata.

The popup is 360 pixels wide and places the settings gear at top right. Website access precedes enhancement controls; embedded-player access uses a single selector. Controls, Compare and HUD are optional and start hidden. Detailed errors and measurements move to advanced settings, which opens with the source tab and selected profile.

Native labels, switches and focus outlines remain visible. Short hover and focus help explains each option; Escape dismisses help. Tooltips avoid controls, and interactive player UI uses isolated frames so native player handlers cannot receive its input. Browser previews and regression checks validate these flows. No private design or session identifiers are part of the public source.
