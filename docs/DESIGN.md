# Design

WebScaly uses dark `#111820`, surface `#18232d`, mint `#79dfbd` and locally bundled Inter. Its identity uses three ascending curved scale plates with a clear silhouette at small sizes. The master and 16/32/48/128 PNG icons are included.

The popup is 360 pixels wide and places the settings gear at top right. Website access precedes enhancement controls; embedded-player access uses a single selector. Controls, Compare and HUD are optional and start hidden. Detailed errors and measurements move to advanced settings, which opens with the source tab and selected profile.

Native labels, switches and focus outlines remain visible. Short, delayed hover and focus help explains technical options; Escape dismisses help. Tooltips avoid controls, and interactive player UI uses isolated frames so native player handlers cannot receive its input. Browser previews and regression checks validate these flows.
