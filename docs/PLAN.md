# Scope and publication status

WebScaly 0.4 provides video enhancement with quality scaling, adaptive sharpening, deband and colour controls, adaptive performance, scoped host approval, keyboard shortcuts, optional comparison, snapshots and diagnostics. Rendering uses native decoded frames and browser capabilities. All player tools start hidden. Public distribution includes clean source without private developer history, explicit package allowlists and LGPL source/rebuild material.

The extension is published on the [Chrome Web Store](https://chromewebstore.google.com/detail/webscaly/hdcnniaagmhkocoeahemlpgjecgpchfa), the recommended installation method. Source and development releases are public on [GitHub](https://github.com/Lorcuz/WebScaly). See [CHROMEWEBSTORE.md](../CHROMEWEBSTORE.md) for listing maintenance and future updates, and [COMPATIBILITY.md](COMPATIBILITY.md) for tested behavior and limits.
