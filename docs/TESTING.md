# Testing

Run `npm test`, `npm run build`, then `npm run test:browser`. Install Chromium once with `npx playwright install chromium`. Raw output stays under ignored `test-results/`; no browser profile, device identity, machine path or old development history is included in release archives.

The release passes 32 unit tests and 36 browser tests. Unit tests cover bounded settings, exact/wildcard scopes, version migration, synchronous approval initiation, denial, duplicate requests, late grants, cancellation, durable intent recovery, parent/player authorization and overlapping removal. Approval unit tests use a Chrome API model. The installed Chrome Add → Allow flow was also manually confirmed to activate without reopening the popup.

Browser tests use fresh isolated profiles and exercise actual MV3 extension code with test-only loopback grants, local generated HTML5 video, recorded playback, dynamically replaced sources, late open Shadow DOM, inherited-origin frames, fullscreen, parent/iframe revocation, reapproval, isolated controls and comparison, compact popup states, accessible full errors, tooltips, WebGPU output readback, native frame pacing, WebGL fallbacks and local tab sharing. Native JW-style control and caption pixels are checked with enhancement active. Actual Video.js/Plyr and generated local HLS/DASH media exercise common player integrations. Capture-phase native event handlers verify that extension controls cannot trigger player clicks or shortcuts. API simulations are recorded separately from physical device checks.

Live-player results are in `docs/COMPATIBILITY.md`. A failed or unavailable live player remains blocked or unverified. Physical AMD and Intel devices require separate qualification. Before store submission, verify native browser restart recovery, denial, parent and overlapping grant removal, and reapproval on the publisher’s installed Chrome profile. Repeat the one-click approval check on the final submitted build.

Package verification recursively inspects the extension ZIP and corresponding-source archive. `npm run verify:release` extracts the actual package and checks all five settings sections, hidden defaults, no initial grants, popup/gear dimensions, About images/disclosure and viewer/diagnostic entry points without missing resources, page errors or external requests. `npm run verify:source` extracts the bundled corresponding source, runs a fresh `npm ci`, unit tests, build and package, then compares every runtime file byte-for-byte. No private developer files are required. Install browser binaries with `npx playwright install chromium`. Test scripts honor `PLAYWRIGHT_BROWSERS_PATH`, use a project-local `.playwright` cache when present, and otherwise use Playwright's normal cache.
