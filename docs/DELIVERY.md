# Release preparation

WebScaly 0.3.0 is an enhancement-only build with opt-in website access, hidden player tools by default, an abstract scale logo, a compact popup and portable source/rebuild material. Existing local Git history and raw test evidence stay private.

Use `dist` for unpacked installation. Release archives and the fresh GitHub source tree are generated by `npm run package`. Review CHROMEWEBSTORE, TESTING and COMPATIBILITY before publishing. One-click Chrome approval was manually confirmed. Live website availability, native denial/restart recovery, physical GPU qualification and publisher details remain release checks; no universal perfect-compatibility claim is made. Publish the clean source export rather than the existing private development repository.
