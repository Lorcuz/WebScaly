# WebScaly support

For a reproducible bug or feature idea, [open a GitHub issue](https://github.com/Lorcuz/webscaly/issues). For a private question, email [notlorcuz@gmail.com](mailto:notlorcuz@gmail.com). You can also contact [Lorcuz on Discord](https://discord.com/users/754255237195235369).

Include your Chrome version, WebScaly version, chosen algorithm and a short explanation of what happened. If useful, include a public page address and a screenshot with private information removed. Do not attach your browser profile, credentials, full configuration export or private video links. Security problems should be reported privately as described in [SECURITY.md](SECURITY.md).

Before reporting a playback problem:

1. Confirm both the video website and any embedded-player website are approved.
2. Try Spatial Detail and a lower output-height limit.
3. Open advanced settings → Diagnostics to read the full error.
4. If direct access is blocked, try the compatibility player and explicitly select your source tab.

Protected video and browser security restrictions may prevent enhancement. See [compatibility results](docs/COMPATIBILITY.md) for the current limits. Reply times depend on maintainer availability.
